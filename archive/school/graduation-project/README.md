## Preservation

The original Microsoft Word document has been preserved unchanged.

A PDF and an OpenDocument version are also provided for easier reading on modern systems.

The converted versions may contain formatting differences introduced during the conversion process.

Spelling, formatting and other characteristics of the original document have been intentionally preserved for historical accuracy.
