# Autodesk Animator Player

This project originally used Autodesk Animator FLI/FLC animations.

The original Autodesk Animator Player (AAPLAY.EXE) was a redistributable
runtime supplied by Autodesk for displaying animations created with Autodesk
Animator.

The executable is not included here. Refer to the original Autodesk Animator
documentation or installation media for the redistributable player.

Original animations were created using 256-color VGA graphics.

MP4 versions are provided only for modern playback compatibility and may
contain visual artifacts introduced during conversion.

MP4 files were generated from the original FLI animations using FFmpeg.
They are provided as viewing copies only and are not replacements for the
original files.
