# Running the Projects with DOSBox

Most software contained in this repository was originally developed for MS-DOS.

Today these programs can usually be executed without modification using DOSBox or compatible DOS emulators.

This document will gradually collect:

- DOSBox configuration examples
- compiler installation notes
- required environment variables
- build commands
- execution examples
- known compatibility issues
- screenshots of the original environment

Whenever possible, instructions will remain simple and rely on original development tools rather than modified versions.
