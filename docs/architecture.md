# Project Architecture

This document describes the overall organization of the projects contained in this repository.

Although many of these programs were developed independently over several years, they often share common design ideas, coding conventions and reusable components.

Future revisions of this document may include:

- project timelines
- relationships between projects
- directory organization
- reusable libraries and modules
- build dependencies
- supported operating systems
- memory models and compiler settings
- development workflow

Whenever possible, the original project structure is preserved.
Any modern explanations are provided separately from the original sources.
